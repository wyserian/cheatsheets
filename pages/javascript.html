JavaScript

JavaScript is a dynamically typed, multi-paradigm language standardized as ECMAScript (ECMA-262). It runs in every browser and on servers through runtimes such as Node.js, Deno, and Bun. A new edition is published every June (ES2015 / ES6 was the major modern update).

  • Engines : V8 (Chrome, Node.js, Deno), SpiderMonkey (Firefox), JavaScriptCore (Safari, Bun). Engines parse code, run it in an interpreter, and JIT-compile hot functions to machine code.
  • Single-Threaded : one call stack per realm; concurrency comes from the event loop and asynchronous APIs, and parallelism from Web Workers / worker threads.
  • Host APIs : the language itself has no I/O. Browsers add the DOM, fetch, and timers; Node.js adds the file system, networking, and processes.
  • Strict Mode : "use strict" turns silent mistakes into errors (e.g. assigning to undeclared variables). ES modules and classes are always strict.

Setup & Running

<script src="app.js" defer></script> <!-- classic script, runs after HTML is parsed --> <script type="module" src="main.js"></script> <!-- ES module: strict, deferred, own scope --> node app.js # run with Node.js node --watch app.js # restart on file changes deno run app.ts / bun app.js # other runtimes

  • Tooling : npm / pnpm / yarn (packages), Vite / esbuild / webpack (bundlers), ESLint (linting), Prettier (formatting), TypeScript (static types).

Types

Seven primitive types are immutable and compared by value; everything else is an object, compared by reference.

Type Example typeof
Number (64-bit IEEE 754 float) 42, 3.14, NaN, Infinity "number"
BigInt (arbitrary precision) 9007199254740993n "bigint"
String (UTF-16) 'hi', `hi ${name}` "string"
Boolean true, false "boolean"
undefined declared but not assigned "undefined"
null intentional absence of a value "object" (historical bug)
Symbol Symbol('id'), unique keys "symbol"
Object {}, [], functions, Date, Map "object" / "function"
  • Safe Integers : numbers are exact only up to Number.MAX_SAFE_INTEGER (253 − 1); use BigInt beyond that. 0.1 + 0.2 !== 0.3 because of binary floating point.
  • Falsy Values : false, 0, -0, 0n, "", null, undefined, NaN; everything else (including [] and {}) is truthy.
  • Type Checks : Array.isArray(x), Number.isNaN(x), x instanceof Date, Object.prototype.toString.call(x).

Operators

5 == "5" // true - loose equality converts types (avoid) 5 === "5" // false - strict equality, no conversion NaN === NaN // false; use Number.isNaN() or Object.is(NaN, NaN) user?.address?.city // optional chaining: undefined instead of a TypeError count ?? 10 // nullish coalescing: 10 only if count is null/undefined count || 10 // 10 if count is any falsy value, including 0 and "" a ||= b; a &&= b; a ??= b // logical assignment 2 ** 10 // 1024, exponent 7 % 3 // 1, remainder "3" + 1 // "31" (+ concatenates if either side is a string) "3" - 1 // 2 (other arithmetic converts to number) typeof x; x instanceof Class; "key" in obj; delete obj.key

Spread / rest : ... expands an iterable or object ([...a, ...b], {...obj, x: 1}) or collects remaining values (function f(...args)).

Functions

function add(a, b = 0) { return a + b; } // declaration: hoisted const mul = function (a, b) { return a * b; }; // expression const square = x => x * x; // arrow function const sum = (...nums) => nums.reduce((a, b) => a + b, 0); const point = ({ x, y }) => `(${x}, ${y})`; // destructured parameter
  • First-Class : functions are objects; they can be stored, passed as arguments (callbacks), and returned (higher-order functions).
  • Arrow Functions : have no own this, arguments, or prototype; they use this from the enclosing scope and cannot be used with new.
  • this : decided by how a function is called: the object before the dot, undefined in strict mode for a plain call, or set explicitly with call, apply, and bind.
  • IIFE : (() => { /* private scope */ })(); runs immediately.
Scope & Closures

JavaScript uses lexical scope: a function can access variables from where it was defined. A closure is a function together with those captured variables, which stay alive as long as the function does.

function counter() { let count = 0; // private: only the returned functions can reach it return { inc: () => ++count, get: () => count }; } const c = counter(); c.inc(); c.inc(); c.get(); // 2
Generators
function* ids() { let id = 1; while (true) yield id++; } // lazy, pausable sequence const gen = ids(); gen.next().value; // 1 gen.next().value; // 2

Prototypes & Classes

Objects inherit through a prototype chain: when a property is missing, the engine looks it up on Object.getPrototypeOf(obj), then that object's prototype, up to Object.prototype. Classes are syntax over this mechanism.

class Animal { #sound; // private field (enforced by the language) static count = 0; // static field, on the class itself constructor(name, sound) { this.name = name; this.#sound = sound; Animal.count++; } speak() { return `${this.name} says ${this.#sound}`; } get label() { return this.name.toUpperCase(); } // getter static create(name) { return new this(name, "..."); } } class Dog extends Animal { constructor(name) { super(name, "woof"); } // super() before using this speak() { return super.speak() + "!"; } // override } const d = new Dog("Rex"); d.speak(); // "Rex says woof!" d instanceof Animal; // true Object.getPrototypeOf(Dog.prototype) === Animal.prototype; // true
  • new : creates an object whose prototype is Class.prototype, runs the constructor with this bound to it, and returns it.
  • Methods : live once on the prototype and are shared by all instances.
  • Prototype Pollution : merging untrusted JSON into objects can set __proto__ and change every object; validate keys or use Object.create(null) / Map.

Event Loop & Async

The event loop runs one task to completion, then runs all queued microtasks, then (in browsers) may render, then takes the next task.

Queue Sources
Call stack synchronous code currently running
Microtasks promise callbacks (then, await continuations), queueMicrotask, MutationObserver
Tasks (macrotasks) setTimeout, setInterval, I/O, UI events, MessageChannel
console.log("1"); setTimeout(() => console.log("4"), 0); Promise.resolve().then(() => console.log("3")); console.log("2"); // prints 1, 2, 3, 4: microtasks run before the next task
Promises & async/await

A Promise represents a future value and is pending, then fulfilled or rejected. An async function always returns a promise, and await pauses it without blocking the thread.

async function loadUser(id, signal) { const res = await fetch(`/api/users/${id}`, { signal }); if (!res.ok) throw new Error(`HTTP ${res.status}`); // fetch rejects only on network errors return res.json(); } try { const controller = new AbortController(); setTimeout(() => controller.abort(), 5000); // cancel after 5 s const user = await loadUser(42, controller.signal); } catch (err) { console.error(err); } await Promise.all([a(), b()]); // run in parallel; rejects on the first failure await Promise.allSettled([a(), b()]); // wait for all, report each result await Promise.race([a(), timeout()]); // first to settle await Promise.any([a(), b()]); // first to fulfill
  • Sequential vs Parallel : awaiting inside a loop runs one request at a time; start them together and use Promise.all when they are independent.
  • Unhandled Rejections : always catch; Node.js terminates the process on an unhandled rejection by default.
  • CPU Work : async does not make CPU-heavy code non-blocking; move it to a Web Worker or worker thread.

Modules

// math.js - ES modules (standard) export const PI = 3.14159; export function area(r) { return PI * r * r; } export default class Circle { } // main.js import Circle, { area, PI as pi } from "./math.js"; import * as math from "./math.js"; const { heavy } = await import("./heavy.js"); // dynamic import, loads on demand // CommonJS (older Node.js) const fs = require("fs"); module.exports = { area };
  • ES Modules : static imports are resolved before the code runs (enabling tree shaking), are always strict, and support top-level await.
  • Node.js : files are ESM when package.json has "type": "module" or the extension is .mjs; otherwise CommonJS (.cjs).
  • Import Maps : <script type="importmap"> maps bare names such as "lodash" to URLs in browsers.

Error Handling

class ValidationError extends Error { constructor(field, options) { super(`Invalid ${field}`, options); // options.cause keeps the original error this.name = "ValidationError"; this.field = field; } } try { JSON.parse(input); } catch (err) { throw new ValidationError("body", { cause: err }); } finally { cleanup(); // always runs }
Built-in Error Thrown When
TypeError a value is the wrong type, e.g. calling undefined or reading a property of null
ReferenceError an undeclared variable is used, or a let/const before its declaration
SyntaxError invalid code or invalid JSON in JSON.parse
RangeError a value is out of range, e.g. invalid array length or too much recursion

DOM & Browser APIs

const btn = document.querySelector("#save"); // first match (CSS selector) const items = document.querySelectorAll(".item"); // static NodeList btn.addEventListener("click", (e) => { e.preventDefault(); save(); }, { once: true }); // event delegation: one listener on the parent handles all children list.addEventListener("click", (e) => { const li = e.target.closest("li"); if (li) select(li.dataset.id); // reads data-id="..." }); const el = document.createElement("li"); el.textContent = userInput; // safe: treated as text el.classList.add("active"); el.setAttribute("aria-selected", "true"); list.append(el);
  • Event Flow : events go through the capture phase (top down), the target, then the bubble phase (bottom up); stopPropagation() stops it.
  • XSS : never assign untrusted strings to innerHTML, outerHTML, document.write, or eval; use textContent, sanitize with DOMPurify, and add a Content Security Policy.
  • Storage : localStorage / sessionStorage (synchronous strings), IndexedDB (large structured data), cookies; see the Networking sheet.
  • Other APIs : fetch, URL / URLSearchParams, IntersectionObserver, requestAnimationFrame, Web Workers, Service Workers, WebSocket, crypto.subtle.

Best Practices

  • Declarations : prefer const, then let; never var.
  • Equality : always use === and !==.
  • Immutability : prefer non-mutating methods (map, toSorted, spread) for shared data.
  • Async : use async/await with try/catch, and cancel requests with AbortController.
  • Security : no eval or new Function on input, validate data from the network, avoid innerHTML, and audit dependencies with npm audit.
  • Memory : remove event listeners and timers you no longer need, and avoid closures that keep large objects alive.
  • Types : use TypeScript or JSDoc types with a linter for larger projects.
