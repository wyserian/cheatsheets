macOS

macOS is Apple's desktop operating system, descended from NeXTSTEP and first released as Mac OS X in 2001. It is a certified UNIX 03 system built on Darwin, the open-source core it shares with iOS (see the iOS sheet).

Version Year Notes

  • Apple Silicon : since 2020, Macs use Apple's ARM-based M-series chips with unified memory and a Secure Enclave. Rosetta 2 translates Intel (x86-64) apps; universal binaries contain both architectures.
  • Check Your System : sw_vers, uname -m (arm64 or x86_64), system_profiler SPHardwareDataType.

Architecture

Apps Finder, Safari, third-party apps Application Frameworks AppKit, SwiftUI, Mac Catalyst Core Frameworks Foundation, Core Data, Core Animation, Metal, Security Darwin XNU kernel (Mach + BSD + IOKit), launchd, libSystem, dyld Hardware Apple silicon / Intel + T2, Secure Enclave
  • XNU : a hybrid kernel: Mach (tasks, threads, virtual memory, IPC ports), BSD (processes, users, POSIX, networking, VFS), and IOKit (object-oriented drivers).
  • launchd : PID 1; starts and supervises daemons and agents, replacing init, cron, and inetd.
  • WindowServer : composites all windows on screen. Finder and Dock are ordinary processes.
  • Mach-O : the executable format; dyld loads libraries, and system libraries live in the dyld shared cache instead of individual files.
  • XPC : IPC used to split apps and system services into separate, privilege-separated processes.
  • System Extensions : DriverKit and system extensions run in user space, replacing most deprecated kernel extensions (kexts).

Boot Process & Startup Modes

Apple silicon: Boot ROM -> LLB / iBoot -> kernelcache (XNU) -> launchd -> loginwindow Intel + T2: T2 Boot ROM -> T2 bridgeOS -> UEFI firmware -> boot.efi -> XNU -> launchd
  • Secure Boot : every stage verifies the next stage's signature. On Apple silicon, the security policy is set per installed OS: Full Security (only current, signed macOS), Reduced Security (older signed versions, third-party kexts), and Permissive Security (custom kernels, SIP disabled).
  • Signed System Volume (SSV) : the system volume is sealed with a hash tree verified at boot, and macOS boots from a read-only snapshot of it.

File System & Paths

  • APFS : the default since macOS 10.13, with copy-on-write, snapshots, clones, space sharing between volumes, and native encryption. Case-insensitive but case-preserving by default.
  • Volume Group : the startup disk is split into a read-only System volume and a writable Data volume, joined by firmlinks so they appear as one tree.
  • Extended Attributes : metadata such as com.apple.quarantine on downloaded files; view with xattr -l file.
Path Contents

/Applications apps for all users

/usr/local, /opt/homebrew Homebrew on Intel / Apple silicon

  • Bundles : apps (.app) are directories shown as one file: Contents/MacOS (binary), Contents/Info.plist, Contents/Resources, Contents/_CodeSignature.
  • Property Lists : configuration is stored in .plist files (XML or binary); convert with plutil -convert xml1 file.plist.

launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.example.backup.plist # load launchctl bootout gui/$(id -u)/com.example.backup # unload launchctl kickstart -k gui/$(id -u)/com.example.backup # restart now launchctl print gui/$(id -u)/com.example.backup # status launchctl list | grep example

Other keys: KeepAlive (restart if it exits), StartInterval (every N seconds), WatchPaths, StandardOutPath. Launch agents and daemons are a common persistence mechanism for malware, so System Settings > General > Login Items lists them and macOS notifies the user when one is added.

Security Architecture

Layer What It Does
Gatekeeper on first launch, checks that downloaded apps are signed with a Developer ID and notarized by Apple
Notarization Apple's automated malware scan of developer-submitted software; a ticket is stapled to the app
Quarantine com.apple.quarantine attribute added by browsers and apps to downloads, which triggers Gatekeeper
XProtect built-in signature-based malware detection, updated silently; XProtect Remediator removes known malware
System Integrity Protection (SIP) stops even root from modifying protected system files, processes, and kernel extensions
Signed System Volume cryptographically sealed system volume
TCC user consent for camera, microphone, screen recording, Full Disk Access, Accessibility, automation
App Sandbox required for Mac App Store apps; restricts files and resources to declared entitlements
Hardened Runtime required for notarization; blocks code injection, unsigned libraries, and debugging unless entitled
FileVault full-disk encryption (XTS-AES-128), keys protected by the Secure Enclave
Secure Enclave Touch ID, FileVault and Keychain keys, Apple Pay
Lockdown Mode optional hardening for people at risk of targeted attacks
csrutil status # SIP state (change only from Recovery) spctl --status # Gatekeeper state spctl -a -vvv -t exec /Applications/App.app # would Gatekeeper allow this app? codesign -dv --verbose=4 /Applications/App.app # signature, team ID, flags codesign --verify --deep --strict App.app xattr -l file.dmg # see the quarantine attribute fdesetup status # FileVault state tccutil reset Camera com.example.app # reset an app's camera permission

Since macOS 15, users can no longer bypass Gatekeeper with Control-click > Open; they must approve the app in System Settings > Privacy & Security.

Users, Keychain & Authentication

  • Accounts : standard and administrator users; root is disabled by default, and admins use sudo. Admins belong to the admin group.
  • Directory Services : user records are stored by opendirectoryd under /var/db/dslocal; query them with dscl.
  • Keychain : stores passwords, certificates, and keys. The login keychain is in ~/Library/Keychains/; the Passwords app (macOS 15) and iCloud Keychain sync credentials across devices.
  • Secure Token & Bootstrap Token : users need a Secure Token to unlock FileVault; MDM uses a bootstrap token to grant it to new accounts.
  • Authorization : the authd service and /etc/sudoers control privilege elevation; Touch ID can be enabled for sudo in /etc/pam.d/sudo_local.
id; whoami; groups dscl . -list /Users # local users dscl . -read /Users/ada # user record sudo dseditgroup -o edit -a ada -t user admin # add to admin group security find-generic-password -s "service" -a "account" -w # read a keychain item security list-keychains sysadminctl -secureTokenStatus ada

Logging & Diagnostics

log show --last 1h --predicate 'process == "sshd"' # unified logging log stream --level debug --predicate 'subsystem == "com.example.app"' log show --predicate 'eventMessage CONTAINS "error"' --info --last 30m sysdiagnose # collect a full diagnostic archive top -o cpu; ps aux; lsof -i :8080 # processes, open ports sudo fs_usage -f filesys App # live file system activity sudo dtruss -p PID # system calls (needs SIP changes) vm_stat; memory_pressure; sysctl -a | grep hw sudo powermetrics --samplers cpu_power # CPU and GPU power use
  • Unified Logging : replaces syslog; entries are compressed binary data in /var/db/diagnostics, with private values redacted by default.
  • Console App : graphical viewer for logs and crash reports (~/Library/Logs/DiagnosticReports).
  • Activity Monitor : CPU, memory, energy, disk, and network per process.
  • Endpoint Security : the framework security tools use to monitor process, file, and authentication events (replacing kernel extensions); also see eslogger.

Terminal Commands

The default shell is zsh (since macOS 10.15). macOS ships BSD versions of tools such as sed, grep, and date, whose options differ from the GNU versions on Linux (e.g. sed -i '' 's/a/b/' file). See the Bash and Linux sheets for common Unix commands.

Device Management

  • MDM : Mobile Device Management servers push configuration profiles, apps, updates, and commands (lock, erase) to Macs using the APNs-based MDM protocol. Declarative Device Management lets the device apply and report state itself.
  • Automated Device Enrollment : Macs bought through Apple Business Manager or Apple School Manager enroll in MDM automatically during setup.
  • Configuration Profiles : .mobileconfig files with settings such as Wi-Fi, VPN, certificates, restrictions, and privacy (PPPC) permissions; listed with sudo profiles show.
  • Platform SSO : lets users log in to the Mac with their identity provider account (e.g. Microsoft Entra ID, Okta).
  • Common Tools : Jamf Pro, Kandji, Mosyle, Microsoft Intune, and open-source tools such as osquery and Munki.
